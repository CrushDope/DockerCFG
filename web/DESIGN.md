# DockerCFG Manager · 前端设计规范

> 版本 2.0 · 重做后的界面规范，覆盖设计令牌、布局骨架、组件规格与交互规则。
> 实现载体：`web/src/style.css`（全局令牌与页面样式）+ 各 `*.vue` 组件的 `<style scoped>`。

## 1. 设计原则

| 原则 | 落地方式 |
|---|---|
| **中文优先** | 页面上一律展示中文字段名；compose 英文键以等宽小字作为副标签，仅作对照 |
| **状态即信息** | 已配置字段在标签旁带蓝色圆点；分组导航显示「已配置项数」；服务项显示容器运行点与未保存标记 |
| **可扫读** | 表单采用「标签列 + 控件列」的设置式栅格，不使用卡片瀑布流，视线沿一条竖线扫下去 |
| **不丢数据** | 未改动的字段保留原始 YAML 值与字段顺序，打开再保存不会重写文件 |
| **键盘可达** | 所有交互元素为原生 `button` / `input`，带 `:focus-visible` 描边与 `aria-label` |

## 2. 设计令牌

### 2.1 颜色

| 角色 | 变量 | 值 | 用途 |
|---|---|---|---|
| 品牌 | `--brand-600` | `#2563eb` | 主色、选中态、焦点环 |
| 品牌浅底 | `--brand-50` | `#eff6ff` | 选中行、悬停底色、图标底 |
| 品牌描边 | `--brand-200` | `#bfdbfe` | 选中项边框 |
| 主文本 | `--ink-900` | `#0f172a` | 标题 |
| 正文 | `--ink-600` | `#334155` | 说明、表单值 |
| 次要文本 | `--ink-400` | `#64748b` | 辅助说明 |
| 弱化文本 | `--ink-300` | `#94a3b8` | 英文键名、占位符 |
| 描边 | `--line-200` | `#e2e8f0` | 卡片 / 输入框边框 |
| 分隔线 | `--line-100` | `#f1f5f9` | 行分隔 |
| 成功 | `--ok-600` | `#047857` | 运行中、已保存 |
| 警告 | `--warn-600` | `#b45309` | 未保存、部分运行 |
| 危险 | `--bad-600` | `#be123c` | 删除、解析错误 |
| 页面底 | `--bg` | `#f1f5f9` | 应用背景 |
| 卡片底 | `--surface` | `#ffffff` | 内容面 |
| 次级面 | `--surface-2` | `#f8fafc` | 表头、嵌套面板 |

语义色一律同时携带底色与描边（药丸容器），保证浅色底上的文字对比度 ≥ 4.5:1。

### 2.2 字体与清晰度

- 界面字体：`Inter → -apple-system → Segoe UI → PingFang SC → Microsoft YaHei`
- 等宽字体：`SFMono-Regular → ui-monospace → JetBrains Mono → Consolas`，用于英文键名、镜像名、YAML
- 字号阶：`12 / 13 / 14 / 15 / 17 / 21 / 27 / 34px`，正文基准 14px，行高 1.55
- Element Plus 同步：`--el-font-size-base: 14px`、`--el-font-size-small: 13px`、`--el-font-size-extra-small: 12px`
- 中文标签 14px、英文键副标签 12px 等宽，保证在 NAS 远端桌面下也清晰可读

**避免文字发虚的四条硬约束**（NAS 远端桌面 + 缩放场景尤其明显）：

| 约束 | 原因 | 做法 |
|---|---|---|
| 字重只用 400 / 600 / 700 | 550、640、650 这类"中间值"在 Segoe UI 等系统字体里没有对应字重，浏览器只能**合成补粗**，笔画发虚 | 全局字重归一到 400/600/700 |
| 不使用负字距 | 中文负字距会把字挤在一起，笔画边缘互相干扰，看着发糊 | 中文标题 `letter-spacing: 0`，仅纯拉丁标题保留 -0.01em |
| 浅色底不用灰度抗锯齿 | `-webkit-font-smoothing: antialiased` 会关闭子像素抗锯齿，Windows 下笔画边缘发虚 | 显式设为 `subpixel-antialiased`，`text-rendering: auto` |
| 关键区域避免 `backdrop-filter` | 它强制创建合成图层，层内文字被降级为灰度抗锯齿 | 吸底保存栏改为 0.98 不透明纯色背景 |

小字号的对比度同时受控：英文键副标签用 `--muted`（#64748b，4.6:1）而非更浅的灰，避免"看不清"叠加"发糊"。

### 2.3 间距、圆角、阴影

- 间距基准 4px：`--sp-1` 4 → `--sp-2` 8 → `--sp-3` 12 → `--sp-4` 16 → `--sp-5` 20 → `--sp-6` 24 → `--sp-8` 32 → `--sp-12` 48
- 圆角：`--radius-xs` 4（标签芯片） / `--radius-sm` 6（输入框、按钮） / `--radius` 9（卡片） / `--radius-lg` 14（面板、模态）
- 阴影：`--shadow-xs` 描边感 → `--shadow-sm` 卡片 → `--shadow-md` 吸底栏 → `--shadow-lg` 登录卡
- 动效：`160ms cubic-bezier(.4,0,.2,1)`；`prefers-reduced-motion` 下全部降为 0.01ms

## 4. 可视化编辑器（核心界面）

### 4.1 三栏工作台

```
┌ 工具条 ──────────────────────────────────────────────────────┐
│ [服务配置|顶层配置]              🔍搜索字段  □仅显示已配置 ⟳  │
├───────────────┬────────────────┬─────────────────────────────┤
│ 服务栏 236px  │ 分组导航 186px │ 表单区 flex                  │
│               │                │                             │
│ 🔍 筛选服务   │ ▣ 基础      3  │ 基础 · 镜像、容器名与运行策略 │
│ ● app         │ ▣ 网络      2  │ ─────────────────────────── │
│   nginx:1.25  │ ▣ 存储      1  │ 容器名称  ● container_name  │
│ ● db          │ ▣ 环境变量 2  │  [_______________________]  │
│   postgres:16 │ ▣ 依赖与标签 2│ 镜像       ● image           │
│               │ ▣ 构建与资源 1│  [_______________________]  │
│ ＋ 新增服务   │ ▣ 健康与日志 2│ 重启策略     restart         │
│               │ ▣ 系统与安全 0│  [ 未设置 ▾               ]  │
│               │                │ ─────────────────────────── │
│               │                │ 正在编辑服务 [app] ⌫ 删除   │
├───────────────┴────────────────┴─────────────────────────────┤
│ ● 有未保存的修改 · 引用型变量的值将同步写入 .env   [保存全部配置]│ ← 吸底
└──────────────────────────────────────────────────────────────┘
```

- **服务栏**：容器运行状态点（绿=运行 / 灰=停止 / 浅=无容器）、镜像名、未保存橙点；可按名称与镜像筛选。
- **分组导航**：竖排替代横向标签页，避免 8 个分组挤在一行；每项带图标与「已配置项数」，为 0 时数字弱化。
- **表单区**：分组头（标题 + 说明 + 计数 + 英文分组键），下方为「标签列 178px + 控件列」的设置式行；行间 1px 分隔，悬停浅底。
- **吸底保存栏**：`position: sticky; bottom: 12px`，半透明白底 + 背景模糊，滚动时始终可见；显示脏状态文案与保存按钮。

### 4.1.1 吸附规则

三处吸附同时生效，滚动时各自固定：

| 元素 | 位置 | 说明 |
|---|---|---|
| 应用顶栏 | `top: 0` | 常驻，便于随时退出登录 |
| 服务栏 / 分组导航 | `top: 74px` | 让开顶栏高度，滚动长表单时保持可见 |
| 吸底保存栏 | `bottom: 12px` | 始终可点保存，不必滚到页面底部 |

> 关键约束：Element Plus 的 `.el-tabs__content` 默认带 `overflow: hidden`，会成为 sticky 的滚动容器并让吸附失效，
> 因此全局样式中必须显式放开 `.detail-tabs > .el-tabs__content { overflow: visible; }`。

### 4.1.2 宽度约束（防溢出）

栅格轨道一律用 `minmax(0, 1fr)` 而不是默认 `auto`，否则长镜像名会按 `max-content` 把轨道撑破容器：

- `.ce-rail` / `.ce-nav` / `.ce-svc-text` 显式声明 `grid-template-columns: minmax(0, 1fr)`
- 服务名 / 镜像名单独使用 `.ce-svc-title` / `.ce-svc-image` 类名（与页脚输入框的 `.ce-svc-name-field` 区分，避免样式串扰）
- 文本层 `min-width: 0` + `overflow: hidden` + `text-overflow: ellipsis`，超出即省略号

### 4.2 字段规格

| 场景 | 规则 |
|---|---|
| 标签 | 中文名（已配置时加粗变深）+ 蓝色圆点 + 英文键（弱化等宽） |
| 单值 | `el-input` / `el-select` / `el-switch`，使用 Element Plus 默认尺寸（`--el-component-size: 38px`），不再用 `small` |
| 列表 | `RowsEditor`：每行一个输入框 + 删除按钮，底部为虚线「添加」按钮 |
| 键值对 | `RowsEditor`：每行「名称 + 取值」双输入框 |
| 宿主机 ↔ 容器映射 | `MappingEditor`：列头标注两侧含义，每行「宿主机输入 → 容器输入 + 模式下拉 + 删除」；用于端口、挂载、设备。端口模式为协议（TCP/UDP），挂载为权限（ro/rw），设备为 r/w/rwm。未改动的行保留原始长语法对象（含键顺序与数字类型） |
| 结构化 | `StructEditor`：浅底圆角嵌套面板，内部两列栅格；面板标题为该字段中文名 + 英文键 |
| 环境变量 | 独立表格：变量名 / 值 / 来源 / 操作；来源为 `.env` ↔ `内联` 分段开关，切换即搬迁取值 |

### 4.3 交互规则

- **搜索**：同时匹配中文名、英文键、帮助文案；命中后自动切到首个有命中的分组，分组导航同步收敛。
- **仅显示已配置**：只保留有取值的字段；空分组自动从导航中消失。
- **服务切换**：重置到「基础」分组，避免带着上一个服务的上下文。
- **未保存标记**：服务栏出现橙点；保存栏文案变为「有未保存的修改 · 引用型变量的值将同步写入 .env」。
- **来源语义**：引用型变量（`${VAR}`）值存 `.env`、compose 保持占位符；字面量直接写入 compose。表头图例常驻说明该规则。

## 6. 可访问性

- 所有输入控件带 `aria-label`（中文名），图标按钮带 `aria-label`，纯装饰图标 `aria-hidden`。
- 焦点可见：`:focus-visible` 统一 2px 品牌色描边 + 2px 偏移；提供「跳转到主内容」跳过链接。
- 导航语义：项目列表用 `ul/li`，分组导航用 `nav[aria-label]`，当前项 `aria-current`；顶栏用真实 `router-link`（可复制链接、可新标签打开）。
- 路由切换后焦点自动落到新页面的 `h1`；离开详情页前若有未保存改动，先弹确认框。
- 状态播报：Docker 连接、保存状态使用 `role="status"`。
- 触控目标：编辑器内按钮最小 28px，主要按钮 40px，移动端断点下升至 44px。

## 7. 响应式

| 断点 | 变化 |
|---|---|
| ≥ 1240px | 编辑器三栏并列，服务栏与分组导航吸顶 |
| 900–1240px | 分组导航转为顶部横向滚动条，服务栏保持左列 |
| < 900px | 单列堆叠；服务栏改为可滚动区块；表单行由「标签左 / 控件右」转为上下堆叠；保存按钮占满宽度 |
